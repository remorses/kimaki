Pick a model with **`/model`**, a thinking level with **`/model-variant`**, and an agent with **`/agent`** or its own **`/<name>-agent`** command.

```diagram
/model          ──▶ provider ──▶ model ──▶ thinking level ──▶ this session | this channel
/model-variant  ──▶ thinking level of the current model  ──▶ this session | this channel
/agent          ──▶ agent dropdown                        ──▶ session (in a thread) | channel
/plan-agent     ──▶ same as /agent, one step, optional prompt and variant
```

Every change in a thread applies **from the next step** of the running session. A change in a project channel becomes the default for **new sessions** in that channel.

## /model

Run `/model` and pick a provider, a model, and a thinking level (only shown when the model has variants). Then choose where it applies:

- **This session**: only in a thread. The session switches model from its next step.
- **This channel**: new sessions in this channel use this model.

With no channel model, Kimaki uses the **OpenCode default model**. Set it in your `opencode.json`:

```json
{
  "model": "anthropic/claude-sonnet-4-5"
}
```

Only providers with credentials show up. Connect one first with [`/login`](../getting-started/subscriptions).

## /model-variant

`/model-variant` changes only the thinking level (for example `low`, `high`, `max`) of the model in use. The values come from the model itself, so they differ per provider.

## /agent and agent commands

`/agent` shows the primary agents of the project. In a thread it switches the session's agent; in a project channel it sets the agent for new sessions.

Kimaki also registers **one slash command per primary agent**, named `/<name>-agent`. It has two optional options:

| Option | Effect |
|---|---|
| `prompt` | Send this prompt with the agent. In a channel this starts a new session. |
| `variant` | Also set the thinking level of the current model (autocomplete lists them). |

```
/plan-agent prompt:how should we split the auth module? variant:high
```

The agent commands follow your agent files. When you add, rename, or delete an agent, Kimaki updates the commands by itself; no restart needed. Discord allows 100 commands per server, so skills are cut first when a project has many.

The thread banner and footer show what runs: `-# *using anthropic/claude-sonnet-4-5 ⋅ plan*`.

## Agent files

Agents are OpenCode agents. Define one as a markdown file in `.opencode/agent/` of the project; the file name is the agent name.

**.opencode/agent/review.md**: a read-only reviewer that never asks before searching.

```markdown
---
description: Review changes without editing files
mode: primary
permission:
  edit: deny
  question: allow
---

Review the current changes. Point out bugs and risky code. Do not edit files.
```

The markdown body is the agent's system prompt. A file with only frontmatter keeps the default prompt and changes only the config fields. A file named like a built-in agent (for example `build.md`) changes that agent.

<Aside>
<Note>
In OpenCode 2 the main session runs the model picked with `/model` (or the OpenCode default). An agent's `model` field does not change it; it applies when the agent runs as a subagent. To pair an agent with a thinking level, use the `variant` option of `/<name>-agent`.
</Note>
</Aside>

### Frontmatter reference

| Field         | Description                                                              |
| ------------- | ------------------------------------------------------------------------ |
| `description` | Shown in the `/agent` dropdown and as the `/<name>-agent` description    |
| `mode`        | `primary` (shown in Discord), `subagent`, or `all`                       |
| `permission`  | Rules like `edit: deny` or `bash: ask`; see [Tool Permissions](../configuration/permissions) |
| `model`, `variant` | Model and thinking level when the agent runs as a subagent          |
| `steps`       | Max agentic iterations                                                   |
| `hidden`      | `true` hides the agent from `/agent` and gives it no slash command       |
| `color`       | Hex color, for example `"#E67E22"`                                       |

See the [OpenCode agents docs](https://opencode.ai/docs/agents/) for every field.

## From the CLI

Set channel defaults without Discord. The bot must be running.

```bash
# default model and thinking level of the current project's channel
kimaki channel model anthropic/claude-opus-4-6 --variant high

# default agent of a specific channel
kimaki channel agent plan --channel 1234567890

# back to the OpenCode defaults
kimaki channel model --clear
kimaki channel agent --clear
```

`kimaki send` takes `--model provider/model` and `--agent <name>` for one session.

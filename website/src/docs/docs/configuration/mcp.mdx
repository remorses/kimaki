Kimaki uses the **MCP (Model Context Protocol) servers** of your OpenCode config. There is no Kimaki-specific MCP setup: a server you add for OpenCode is available in every Kimaki session too.

```bash
opencode mcp list     # configured servers and their status
opencode mcp add      # add a server
opencode mcp auth     # log in to a server that uses OAuth
```

Kimaki and the OpenCode CLI use the same OpenCode service, so a change shows up in Discord without a Kimaki restart.

<Aside>
<Note>
Kimaki V2 has no `/mcp` slash command. Use the `opencode mcp` commands above, or edit the `mcp` section of your `opencode.json`.
</Note>
</Aside>

## MCP tools in a thread

MCP tool calls appear in the thread like other tools: a `-# ┣ <tool name>` line. They are hidden at the `text` [verbosity](../configuration/verbosity).

## MCP prompts

OpenCode names MCP prompts `server:prompt`. Because of the colon they get **no slash command** in Discord. Run them in one of these ways:

```
/github:review-pr 123                            ← send as a normal message in a thread
/queue-command command:github:review-pr arguments:123   ← run after the current turn
```

```bash
kimaki session command github:review-pr 123      # from the terminal
```

See [OpenCode Commands](../features/opencode-commands) for how commands, skills, and MCP prompts map to slash commands.

Prefix any Discord message with **`!`** to run it as a shell command in the project directory, no AI session involved. It's the fastest way to peek at state, run a quick script, or check git status.

## Using the `!` prefix

```diagram
  "!git status" ──▶ strips "!" ──▶ runs in dir ──▶ output streams into one message
```

Type a message starting with `!`. Kimaki strips the `!` and runs the rest as a shell command:

```
!pnpm test
```

The reply **streams** while the command runs. Kimaki edits the same message about once per second, so you see progress live:

````
```
 ✓ src/utils.test.ts (12 tests)
 ✓ src/cli.test.ts (8 tests)
```
-# exit 0 ⋅ 4.2s
````

- **stdout and stderr** are interleaved in the order the command prints them.
- The last line is a small subtext footer: `running...` while it runs, then the **exit code** and duration.
- Colors are stripped. Progress bars that redraw with `\r` show only their latest state.
- When output grows past one Discord message, it continues in new messages (up to 5). Past that, the last message shows the **tail** of the output with a count of hidden lines.
- Commands are killed after 10 minutes.

## Shell command buttons

The agent can show **action buttons** that run a shell command, for example a **Build** button that runs `pnpm build`. The message above the buttons shows each command, so you see what runs before you click. Clicking one runs the command at once, the same as sending `!pnpm build` yourself. There is no model turn between the click and the output, so the feedback loop is fast.

## Where it runs

- **In a thread** with a [worktree](../features/worktrees) that is ready, the command runs in the **worktree directory**.
- **Otherwise** it runs in the channel's **project directory**.

This means `!` commands always run in the same place the agent is working.

<Aside>
<Note>
While a worktree is still being created, `!` commands are skipped so they don't accidentally run in the base directory.
</Note>
</Aside>

## The slash command equivalent

`/run-shell-command <command>` does exactly the same thing as the `!` prefix. The `!` prefix is just a shortcut.

## What it's good for

- **`!git status`**, **`!git log --oneline -5`** — quick git checks.
- **`!ls`**, **`!cat package.json`** — inspect files without spending an agent turn.
- **`!pnpm test`** — kick off a one-off command directly.

For long-running servers you want to view remotely, use [Tunnels](../remote-access/tunnels) instead.
